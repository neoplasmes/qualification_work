Кнопка для действия, которое меняет данные: продать, сохранить, отменить операцию.

- Класс `bt-btn`. Залитая кнопка на экране одна, это главное действие. Остальные `bt-btn--ghost`.
- `bt-btn--lg` для главной кнопки формы запуска, `bt-btn--wide` растягивает на ширину колонки.
- Подпись называет результат и, если можно, количество: «Продать 2 шт.». После нажатия то же слово в сообщении: «Продано 2 шт.».
- Выключенная кнопка объясняет причину своей подписью или подсказкой рядом.
- Для перехода между экранами и для «Отменить» в строке журнала берите `Link`, не кнопку.
- Углы прямые, пилюль нет. У второстепенной кнопки пунктирная рамка, под курсором она становится сплошной и заливается `marker`.
