Выбор одного варианта из двух-пяти: сцепленные прямоугольники, выбранный залит чернилами.

- Обёртка `bt-choice` с `role="group"` и `aria-label`, внутри `<button aria-pressed>`.
- Берите вместо свободного текста везде, где значения известны заранее: канал продажи, вид графика, фильтр журнала.
- Больше пяти вариантов или длинные подписи: выпадающий список в виде `Token`.
- Для включить/выключить используйте тумблер, не `Choice` из двух кнопок.
