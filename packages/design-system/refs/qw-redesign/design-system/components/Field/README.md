Поле ввода как строка на бланке: подпись гротеском, линейка снизу, введённое значение шрифтом машинки.

- `bt-field` оборачивает `<label>`, `bt-input` и необязательную подсказку `bt-hint`.
- Рамки вокруг поля нет, только нижняя линейка `ink`. В фокусе строка заливается маркером.
- Подпись всегда видна над полем. Пример значения идёт в placeholder и начинается со слова «Например».
- Тип данных не пишем словами «text» или «number»: число получает `bt-stepper`, дата получает значение «Сегодня» по умолчанию, список получает `Choice`.
- Ошибка: `bt-field--error`, текст под полем говорит, что не так и как исправить.
