Подчёркнутый текст, который под курсором заливается маркером, а в текущем состоянии чернилами. Основной способ перейти куда-то или запустить лёгкое обратимое действие.

- Класс `bt-link` на `<a href>` для переходов и на `<button>` для действий без перехода.
- Текущий раздел или вкладка: `aria-current="page"`, пункт залит чернилами, текст светлый, подчёркивания нет.
- `bt-link--quiet` (пунктир, `ink-3`) для третьестепенного: «Показать ещё», «Настроить правила».
- `bt-link--danger` (`red-ink`) только для отмены и удаления.
- Отдельно стоящей ссылке добавьте `bt-link--block`, чтобы высота цели была 44px.
- Подпись говорит, куда ведёт: «Открыть график», а не «Подробнее». Стрелку в конец не ставим.
