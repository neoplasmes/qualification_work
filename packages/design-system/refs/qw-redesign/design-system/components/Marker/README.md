Мазок маркера под значением, которое изменится или уже изменилось.

- `bt-diff` показывает «было → стало»: `<del>` зачёркнуто серым, `<ins>` на маркере. Всегда шрифтом машинки.
- `bt-mark` выделяет одно новое значение или новую строку.
- Маркер означает только изменение. Не выделяйте им важное, новое или рекомендуемое.
- Если новое значение недопустимо (остаток ушёл в минус), текст внутри маркера красный и со знаком.
