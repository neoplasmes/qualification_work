Шапка: название засечками, разделы ссылками, сплошная линейка снизу.

- `bt-nav` на `<nav>`, внутри `bt-nav__brand`, `bt-nav__links` и `bt-nav__side`.
- Разделы это обычные `Link`. Текущий раздел получает `aria-current="page"` и заливку чернилами.
- Иконок в шапке нет. На узком экране ряды переносятся.
- Справа организация и профиль тихими ссылками.
