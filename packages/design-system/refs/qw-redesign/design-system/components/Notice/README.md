Предупреждение, с которым можно сразу что-то сделать.

- `bt-notice`: красная рамка `red-ink`, фон прозрачный, ярлык красным, текст чернилами. Заливки у предупреждений нет: их выделяет только обводка.
- Справа одно действие, которое решает проблему: кнопка или ссылка.
- Текст называет факт и порог: «осталось 2 шт. при минимуме 5».
- Только для того, что требует решения. Для подтверждения успеха используйте строку текста и `Marker`.
- На экране не больше двух предупреждений подряд, остальные сворачиваются в ссылку «Ещё 3».
