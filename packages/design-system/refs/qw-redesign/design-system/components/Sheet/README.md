Лист бумаги на столе: поверхность для формы, предпросмотра или отчёта.

- `bt-sheet` лежит на `canvas`. `bt-sheet--raised` для листа поверх листа, `bt-sheet--well` для утопленной области загрузки файла.
- Шапка `bt-sheet__head`: заголовок засечками слева, ярлык справа, под ними сплошная линейка.
- Внутри разделы делит пунктир `bt-rule`, вложенных листов и рамок нет.
- Лист нужен целому документу. Список, фильтры и строка кнопок лежат прямо на столе без листа.
- Углы прямые, наружной тени нет.
