Таблица как страница бухгалтерской книги: машинописные числа, пунктир между строками, двойная линейка под итогом.

- Класс `bt-table`. Числа справа, текст слева (`bt-l`), цифры одной ширины.
- Заголовки столбцов: ярлык прописными над сплошной линейкой. Название столбца показываем как в файле пользователя.
- Выбранная строка: `aria-selected="true"`, вся залита маркером.
- Отрицательные значения: класс `bt-neg` и знак минус.
- Строка итога в `<tfoot>`, только если итог имеет смысл для столбца. Пустые ячейки оставляем пустыми.
- Широкую таблицу кладём в контейнер с `overflow-x: auto`, страница вбок не прокручивается.
- Зебры, вертикальных линеек и фона у шапки нет.
