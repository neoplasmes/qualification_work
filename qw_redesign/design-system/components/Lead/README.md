Вводный абзац засечками, с буквицей или на тёмной вставке.

- `bt-lead`: 20px, засечки, ширина до 65 знаков. Один на экран, сразу под названием.
- Выделение внутри абзаца: `<em>`, курсив. Жирного в засечках нет.
- Буквица `bt-dropcap`: первая буква в пунктирной рамке цветом `accent-orange`. Только на стартовом и пустых экранах, где человек читает, а не работает. Саму букву продублируйте скрытым текстом для программ чтения с экрана.
- Тёмная вставка `bt-night`: подтверждение после запуска действия. Кнопки внутри неё светлые.
- В рабочих экранах с таблицами и формами буквицу не используем.
