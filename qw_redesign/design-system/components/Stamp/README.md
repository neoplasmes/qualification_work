Штамп: короткий статус или тип записи в рамке, прописными.

- `bt-stamp` для нейтрального статуса, `bt-stamp--void` (красный) для отменённого, `bt-stamp--draft` (пунктир) для несохранённого.
- Одно-два слова. Не интерактивен, по нему не нажимают.
- Цвет не единственный признак: слово в штампе всегда называет состояние.
