Одно крупное число с подписью и изменением.

- `bt-stat`: ярлык `bt-label`, число `bt-stat__fig` засечками, изменение `bt-stat__delta` шрифтом машинки.
- Красным (`bt-neg`) красим то, что плохо для бизнеса, а не то, что со знаком минус: выросший расход красный.
- Изменение всегда со словами, к чему сравниваем.
- Не больше четырёх чисел в ряд. Рамку вокруг каждого не рисуем, числа разделяет воздух `space-64`.
