Слово в рамке: изменяемая часть предложения в конструкторе действия или графика.

- Предложение `bt-sentence` набрано засечками, внутри обычные слова в `<span>` и рамки `bt-token` на `<button>`.
- Пунктирная рамка: значение выбрано из данных (таблица, столбец, константа). По нажатию открывается список.
- `bt-token--field` (маркер, сплошная рамка): сюда подставится то, что сотрудник введёт при запуске.
- `bt-token--add` добавляет ещё одну часть предложения.
- Предложение должно читаться вслух как нормальная русская фраза. Если не читается, меняйте слова между рамками, а не добавляйте рамки.
